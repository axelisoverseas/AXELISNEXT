§2 · The idea

The category looks like software. Axelis looks like paper.

The real differentiator is not the counselling. It is that the outcome — and the refund if the outcome fails — exists as a document a student can hold. Competitors promise. Axelis signs.

Always

  • State the term, with its clause number
  • Number with a source behind it
  • Name what the guarantee does not cover
  • Rupees in full: ₹2,00,000
  • Sentence case, Indian English, Oxford comma

Never

  • Globes, aeroplanes, passports, graduation caps, rockets
  • Gradient buttons, glows, pills, floating 3D objects
  • Exclamation marks in published copy
  • Dream, journey, unlock, empower, seamless, fly
  • Stock photos of students with backpacks
§3 · The mark

The Axial A

The letter A with two departures. The right stroke is inclined 23.4° from vertical — the Earth's axial tilt, so studying abroad is in the mark without a globe in it. The crossbar runs past both legs as a rule: the line a document is signed on.

Primary · Axis on paper
Reverse · Brass on field
56 / 32 / 16px — still an A at favicon size
The seal · three uses only
The seal is not a logo. It appears on the programme certificate, the signed guarantee page of a proposal, and the enrolment agreement. Nowhere else — using it as decoration spends the one asset that makes the guarantee feel real.

§5 · Typography

Source Serif 4, IBM Plex Sans, IBM Plex Mono

Three open-licensed families, all present in Google Docs, Google Fonts, Adobe Fonts and on the web — so a fee table in a PDF and the same table on the site set identically. Montserrat is retired; it is the default typeface of the Indian education category.

Display
Source Serif 4 · 600Three programmes. One guarantee, in writing.
Quote
Source Serif 4 · 400 italic“If you receive no offer, clause 4 applies.”
Body
IBM Plex Sans · 400

Axelis takes a small number of students end to end — application to admission — under terms that are written down, including what happens if we fail. Body copy is never set wider than 62 characters.

Figures
IBM Plex Mono · 400₹2,00,000 · ₹8,334/mo · AXC-2026-0001
Why monospace for money. Setting fees and certificate IDs in a mono face makes them read as figures on an instrument rather than marketing numbers. Always with tabular-nums, so columns of rupees align.

The guarantee does not cover visa refusal on grounds of document fraud.

Never write “guaranteed admission.” Axelis does not guarantee admission; it guarantees a defined remedy on a defined failure. Write “written outcome guarantee” and link the clause. This is a brand rule because it is also a legal one.
